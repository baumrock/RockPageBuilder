# FAQ

## Can I use RockPageBuilder for building column/grid-layouts?

Yes!

You can add a repeater field to your block and then show every repeater item in a separate column. I decided to go this route to make sure that the pagebuilder is still very easy to use and to avoid too much nesting where clients need to study web development before they can really use the tool.

When using a repeater field RockPageBuilder will automatically show the "plus" icon for every item horizontally making it very easy and intuitive for the client to add new content:

## Can I use RockPageBuilder for building sidebar-layouts?

Yes!

By default RockPageBuilder will create one content field that you can use for regular page content. But you can add as many RockPageBuilder fields as you want to your site. You can even share blocks across those fields, meaning you define them once and you can use them in multiple fields.
